# 水下机器人控制系统

基于 MATLAB 开发的水下机器人（ROV）综合控制软件，具备美观的海洋主题界面、完善的登录验证与丰富的操作功能。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| 🔐 登录界面 | 海洋深色主题，支持多账号验证 |
| 🧭 导航控制 | 前进/后退/左转/右转/上浮/下潜，目标深度设定 |
| 📡 传感器监控 | 深度、水温、水压、盐度、溶解氧、电量、信号强度实时显示 |
| 🔊 声纳扫描 | 实时旋转声纳图，显示障碍物距离信息 |
| 📷 水下摄像头 | 仿真水下摄像头视图，支持亮度/对比度调节与截图保存 |
| 🦾 机械臂控制 | 四关节机械臂 + 夹爪，滑块精确控制，支持复位/抓取/释放 |
| 🗺️ 任务规划 | 多路点任务规划，支持自动执行 |
| 📊 数据日志 | 实时记录传感器数据，支持 CSV 导出 |
| ⚡ 推进器状态 | 六个推进器功率实时条形图显示 |
| 🛑 紧急停止 | 一键紧急制动，可一键解除 |

---

## 文件结构

```
underwater_robot/
├── launch.m          — 启动入口（运行此文件）
├── LoginGUI.m        — 登录界面
├── MainDashboard.m   — 主控制台（含所有子面板）
└── RobotState.m      — 机器人状态共享数据类
```

---

## 快速启动

1. 打开 MATLAB（R2020b 或更高版本）
2. 将工作目录切换至 `underwater_robot/` 文件夹
3. 在命令行运行：

```matlab
launch
```

## 界面截图

### 登录界面
- 深海蓝色主题背景
- 波浪动态装饰元素
- 用户名/密码输入框

### 主控制台
- **左栏**：导航控制按钮组（前/后/左/右/上浮/下潜）、传感器数值面板、紧急停止
- **中栏**：声纳扫描极坐标图（实时旋转）、水下摄像头仿真视图
- **右栏**：推进器状态（6个推进器功率条）、机械臂控制（4关节+夹爪）、任务规划路点列表、数据日志

## 系统要求

- MATLAB R2020b 或更高版本
- 需要 `uifigure`/`uiaxes` 支持（MATLAB App Designer 相关组件，R2016a+ 均支持）

---

## 注意事项

- 本软件为**仿真演示**版本，传感器数据为模拟生成，不连接真实硬件
- 如需接入真实 ROV 硬件，请修改 `RobotState.m` 中的数据采集方法，将模拟数据替换为实际串口/网络通信读取
